# STT 集成测试计划

## 测试目标

验证 Screen Time Guardian 各模块的端到端功能，确保：
- 会话生命周期完整无丢失
- P2P 同步数据一致
- 提醒倒计时基于绝对时间
- 跨设备去重准确
- iOS ScreenTime 数据与系统对齐

## 测试环境

| 平台 | 要求 |
|------|------|
| macOS | Xcode 15+, Swift 5.9+ |
| iOS | 真机, iOS 16+, 需要 Apple Developer 账号 |
| Android | Android 13+ 真机或模拟器 |
| 网络 | 两台设备在同一 WiFi 下（P2P 测试） |

## 测试矩阵

### T1: 会话生命周期

| 用例 | 操作 | 预期 |
|------|------|------|
| T1.1 | 启动 App → 等 30 秒 → 查看数据 | 创建 1 条 session，duration ≥ 30 |
| T1.2 | 使用中锁屏 → 解锁 | 旧 session 关闭(stopAction=screen_locked)，新 session 创建 |
| T1.3 | 使用中合盖休眠 → 开盖 | 旧 session 关闭(stopAction=standby)，新 session 创建 |
| T1.4 | 正常退出 App | session 关闭(stopAction=app_exit) |
| T1.5 | 崩溃后重启 | 异常 session 被 recovery 关闭(stopAction=crash_recovered) |
| T1.6 | 跨日使用（23:59→00:01） | session 在 00:00 被切分(date_rollover) |

### T2: 护眼和姿势提醒

| 用例 | 操作 | 预期 |
|------|------|------|
| T2.1 | 设置护眼间隔=3分钟，等待 | 3分钟后弹出护眼提醒，20秒倒计时 |
| T2.2 | 姿势开关开启，等待 6 分钟 | 第2次提醒包含姿势切换 |
| T2.3 | 姿势开关关闭，等待 6 分钟 | 所有提醒都是护眼提醒 |
| T2.4 | 会议模式开启 | 提醒弹窗显示"会议模式：可以立即关闭"，可直接关闭 |
| T2.5 | 会议模式关闭 | 倒计时期间无法关闭 |
| T2.6 | 倒计时中切到后台→回来 | 剩余秒数按真实时间计算（不重置） |
| T2.7 | 提醒触发时检查 session | 旧 session 关闭(stopAction=eye_rest_prompt/posture_rest_prompt) |
| T2.8 | 提醒关闭后 | 新 session 自动创建 |

### T3: 每日计划与超时提醒

| 用例 | 操作 | 预期 |
|------|------|------|
| T3.1 | 设置计划=5分钟，使用超5分钟 | 超时提醒弹出 |
| T3.2 | 超时后继续使用 | 25分钟后再次提醒 |
| T3.3 | 会议模式下超时 | 提醒可立即关闭 |

### T4: P2P 同步

| 用例 | 操作 | 预期 |
|------|------|------|
| T4.1 | 两台设备同一 WiFi，启动 P2P | 互相发现对方 |
| T4.2 | A 设备同意 B 设备 | B 出现在已同意列表 |
| T4.3 | B 设备同意 A 设备 | 双向信任建立 |
| T4.4 | A 使用 10 分钟 → 同步 → B 查看报告 | B 报告中包含 A 的数据 |
| T4.5 | A 和 B 同时使用 9:00-10:00 → 同步 | 总用时 = 1小时（不是2小时） |
| T4.6 | A 删除一条 session → 同步 | B 收到墓碑，该 session 从 B 删除 |
| T4.7 | 未同意设备尝试同步 | 被拒绝，数据不导入 |

### T5: 跨设备去重

| 用例 | 操作 | 预期 |
|------|------|------|
| T5.1 | 设备A 9:00-10:00，设备B 9:00-10:00 | 去重后总用时 = 1小时 |
| T5.2 | 设备A 9:00-10:00，设备B 10:00-11:00 | 去重后总用时 = 2小时 |
| T5.3 | 设备A 9:00-10:30，设备B 10:00-11:00 | 去重后总用时 = 2小时 |
| T5.4 | 各设备自己的用时统计 | 仍按设备单独累计，不丢失 |

### T6: iOS ScreenTime 对齐

| 用例 | 操作 | 预期 |
|------|------|------|
| T6.1 | 使用 10 分钟，查看系统 ScreenTime | App 记录 ≥ 系统的 90% |
| T6.2 | 中间锁屏 5 分钟 | 锁屏时间不计入 App 记录 |
| T6.3 | checkpoint 间隔 = 2 分钟 | 每 2 分钟一个数据点 |

### T7: 数据持久化

| 用例 | 操作 | 预期 |
|------|------|------|
| T7.1 | 使用 5 分钟 → 强制杀 App → 重启 | 数据不丢失，异常 session 被恢复 |
| T7.2 | 修改设置 → 杀 App → 重启 | 设置保留 |
| T7.3 | 跨日数据 | 正确按日期拆分 |

### T8: 报告准确性

| 用例 | 操作 | 预期 |
|------|------|------|

| T8.2 | 多日报 | 区间去重总用时、日均、各天明细 |
| T8.3 | 各设备分别用时 | 每个设备单独显示 |
| T8.4 | 周统计 | 上周平均、各平台统计 |

### T9: LLM Ranking 跟踪

| 用例 | 操作 | 预期 |

### T10: 平台一致性

| 用例 | 检查项 | 预期 |
